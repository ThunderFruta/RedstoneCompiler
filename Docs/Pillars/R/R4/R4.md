# R4 — Preserve global routing awareness throughout search

**Status:** target behavior.

**Primary owner:** `PhysicalDesign/Routing/Global/`.

## Goal

Carry global fanout, crossing, congestion, corridor, portal, lease, and
boundary-capacity constraints through candidate generation, placement feedback,
assignment, and repair.

## Required behavior

- Plan each producer's branching connections as one signal tree where
  appropriate.
- Represent shared corridors and exclusive resources before local commitment.
- Keep port, portal, corridor, boundary-lease, and local-interface choices
  jointly revisable until they are compatible.
- Return scoped conflicts and repair opportunities to the coordinator.
- Preserve globally compatible work when one region or signal changes.
- Prevent independent shortest-path choices from silently overcommitting shared
  capacity.
- Maintain deterministic assignment and ownership commitment.

## Boundary rules

The global planner returns provisional plans, dependency manifests, and scoped
conflicts. It does not mutate accepted placement state or independently commit
accepted ownership.

## Reuse and stale-result rules

A global result is stale when any relevant demand, capacity, ownership,
corridor, portal, lease, fanout, model, or policy dependency changes. Selective
salvage operates per signal, branch, corridor, lease, or assignment component.
The whole global plan is not retained merely because its top-level plan ID or
placement ID matches.

An old global infeasibility proof survives only when its exact domain remains
exhausted and no relevant constraint was relaxed or choice domain expanded.

## Acceptance

- Shared producers and reconvergent paths preserve all required sinks.
- Capacity-one resources never receive conflicting accepted ownership.
- A change confined to one certified scope does not discard unrelated global
  work.
- A changed portal, lease, or foreign reservation invalidates every dependent
  result and no unrelated result.

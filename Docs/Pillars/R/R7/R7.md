# R7 — Keep policy in Python and native kernels narrow

**Status:** target behavior; the current Runtime checkpoint preserves the
boundary but does not implement or accept R7 in full.

**Primary owners:** Python physical-design packages and `Kernels/Routing/`.

## Goal

Keep planning, policy, orchestration, scheduling, cache decisions, diagnostics,
and commitment in Python. Use Rust for measured computational hotspots exposed
through typed, bounded calls.

## Current frontier

`f083554` adds immutable typed work/result documents and a synchronous
Python-owned bounded-work adapter; `9f432cd` adds a Python spawned-process
admission path, and `f5ffd47` repairs its child failure classification. These
commits add no `Kernels/Routing` source, native interface, native cancellation,
or measured hotspot expansion. They retain policy and publication decisions in
Python, but they do not establish R7 acceptance or native/Python parity beyond
the recorded Runtime contract tests.

## Python ownership

- Candidate generation and ranking.
- Global coordination and retry policy.
- Repair selection.
- Objective evaluation and comparison.
- Worker scheduling and priority changes.
- Cache identity, invalidation, and admission.
- Stale-result review policy.
- Deadline allocation, cleanup-cutoff selection, pressure assessment, and
  interpretation.
- Diagnostics, reporting, and publication decisions.

## Rust ownership

- Path expansion.
- Large claim intersections.
- Bounded assignment and constraint operations.
- Parallel inner loops justified by measurement.
- Private per-call or worker-local native execution state.

Native calls must accept typed immutable inputs and return typed results with
work, dependency, completion, and failure information. They must observe
deadlines and cancellation at bounded intervals.

Rust does not own application reporting, Fabric lifecycle, acceptance cases,
global retries, cache policy, task promotion, stale-result certification, or
accepted-state commitment.

## Stale-result rule

Native kernels may return dependency witnesses and non-interference evidence.
They cannot declare an old result reusable. Only the Python coordinator applies
[N6](../../N/N6/N6.md), issues a reuse certificate, and commits accepted state.

## Acceptance

- Native interfaces contain no Python orchestration or publication objects.
- Long native work honors bounded cancellation and deadline checks.
- Python can explain and test every policy decision independently of kernel
  implementation.
- Native and Python fallback/reference cases agree on result semantics.
- Measured hotspot evidence justifies every expanded native responsibility.

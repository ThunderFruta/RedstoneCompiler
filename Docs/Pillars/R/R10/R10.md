# R10 — One shared pre-validation redstone model

**Status:** target behavior.

**Primary owner:** `PhysicalDesign/Redstone/`.

## Goal

Provide one versioned model of supported cells and blocks for placement,
routing, resource construction, shortcut evaluation, final static checking,
and rendering before authoritative physical validation.

## Required scope

| Responsibility | Required behavior |
|---|---|
| Geometry | Occupancy, support, headroom, transforms, legal step geometry, and port access |
| Connectivity and influence | Dust connections, block roles, powered-block influence, and unwanted coupling |
| Directed power | Sources, decay, refresh sites, repeater direction, branch sinks, and isolation |
| Timing and state | Explicitly supported delays, update assumptions, and stateful scope |
| Diagnostics | `Legal`, `Illegal`, or `Unknown` decisions with claims, positions, assumptions, and reasons |

## Ownership

- `PhysicalDesign/Cells/` owns cell definitions, ports, transforms, and
  model-facing template information.
- `PhysicalDesign/Redstone/` owns physical and electrical rules.
- `PhysicalDesign/Resources/` projects the selected model into routing
  resources.
- `PhysicalDesign/Contracts/` owns portable decisions, claims, and version
  identities.
- `PhysicalDesign/Rendering/` consumes checked decisions and does not redefine
  redstone behavior.

The model performs local queries and does not start global searches, run live
servers, rank layouts, or publish artifacts.

## Version and stale-result rules

The selected model and technology versions participate in every applicable
cache, proof, request, and result identity. A version mismatch invalidates an
old legality claim by default.

Selective salvage requires a model-supplied compatibility rule proving that
the changed versions are equivalent for the exact queries, orientations, and
block arrangements involved. A broad assertion that the change is unrelated is
insufficient.

## Acceptance

- Conformance fixtures cover rotations, mirrors, flat and vertical dust,
  support/headroom boundaries, repeater direction, signal-strength limits,
  fanout, foreign nets, and relevant powered-block interactions.
- Placement, routing, resource construction, static checking, and rendering
  agree on the same model decisions.
- `Unknown` never becomes a behavioral pass.
- Model predictions are compared with MCHPRS and Fabric observations; retained
  disagreements become regressions.
- The model remains cheap enough for search through cached masks and local
  queries without weakening exact refinement.

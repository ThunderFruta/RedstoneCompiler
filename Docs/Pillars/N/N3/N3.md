# N3 — Verifiable reuse and coordinator-only commitment

**Status:** necessary requirement.

**Primary owner:** `PhysicalDesign/Orchestration/`.

## Goal

Make reuse, result selection, and accepted-state mutation deterministic,
auditable, and safe across workers, caches, retries, and snapshot changes.

## Required behavior

- Workers consume immutable snapshots and typed work requests.
- Results carry task, snapshot, dependency, policy, technology, model, budget,
  work, outcome, proof, and diagnostic identities.
- Reusable claims carry immutable claim-specific dependency manifests.
- One opaque fingerprint may summarize a manifest but cannot replace the
  dependency information required for selective comparison.
- Cache keys cover topology, ordered port roles, orientation, model and policy
  versions, boundary contracts, and relevant external reservations.
- Completion order never decides which candidate wins a completed deterministic
  portfolio.
- One coordinator validates compatibility and commits accepted ownership in a
  stable order.
- Workers, caches, kernels, rendering, and validation cannot mutate accepted
  state independently.

## Mutation boundary

Portable contracts exclude process pools, native handles, mutable caches,
private solver sessions, and permission to commit. Mutable run-local services
have explicit owners and expose narrow capabilities.

## Stale-result relationship

[N6](../N6/N6.md) refines this requirement. A dependency fingerprint establishes
identity or difference; it does not prove that a difference is irrelevant.
Only a coordinator-issued reuse certificate can make a selectively salvaged
claim eligible for current-snapshot revalidation.

## Acceptance

- Stale results never enter accepted state without explicit review.
- Different worker completion orders produce the same accepted result.
- Every cache hit reports the assumptions and claim scope reused.
- Mutation tests prove that workers and results cannot alter accepted state.
- Dependency changes invalidate all and only dependent certified claims.

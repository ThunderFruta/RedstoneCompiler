# Synthetic placement viewer

Interactive view of the deterministic synthetic PCB placements generated for
the Freerouting benchmark. The page includes FullAdder, RCA4, RCA8, and CLA4.

From this directory:

```bash
npm install
npm start
```

Open <http://127.0.0.1:4173/>. The server reloads the page when `index.html`
changes.

These are synthetic PCB placements for external-router comparison. They are
not native Redstone placements or proof of Minecraft materialization.
